## 📌 Overview

This project is a full-stack task management application built using React and Firebase.  
It allows users to manage tasks with real-time data storage using Firestore.

---

## 🚀 Features

- View tasks from Firebase Firestore  
- Add a new task using a form  
- Mark tasks as complete or incomplete  
- Delete tasks  
- Real-time updates from database  
- Responsive and modern UI
